# Selfmail

EU-first privacy focused email provider for your company. The goal behind Selfmail is an complete Email Service Provider from scratch, hosted in the eu, that not only respects your secrets, but also looks dope and acts fast! 

**State of development**

Selfmail is in a very early stage, the project contains ~30k LoC and most of it is written by a real human. It is not ready for any beta phases yet.
