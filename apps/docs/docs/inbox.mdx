## Choose an inbox

The **unified inbox** combines incoming mail for the addresses assigned to you in the current workspace. Select an individual address in the sidebar to narrow the list to that address.

Changing workspaces changes the addresses and mail available to you. Workspace membership alone does not mean every address is assigned to you.

## Read a message

Select a message to open it. On wider screens, the preview appears beside the list; smaller screens use a dedicated message view. The message shows its sender, recipients, subject, and body. Opening an unread message marks it as read.

Use the preview's fullscreen control when you want more room to read, and close the preview to return to the list.

## Keyboard controls

| Key | Action |
| --- | --- |
| Arrow down / Arrow up | Move through messages when the inbox list or page body has focus. |
| Escape | Close the active preview or compose panel outside fullscreen mode. |

List navigation does not take over while you type into a field or interact with a dialog or menu.

## Compose availability

The compose panel includes sender and recipient fields, an editor, and attachment selection. Sending and persistent draft saving are not connected yet. Do not use the panel to deliver mail or store a draft you need to keep.

Attachment indicators in the message preview do not currently provide attachment downloads.
