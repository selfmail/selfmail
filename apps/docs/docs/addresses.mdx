An address is where you receive mail, such as `hello@abc1234.selfmail.app`. A workspace can contain multiple addresses, and your sidebar lists the ones assigned to you.

## Add an address

1. Open the workspace where you want the address.
2. Choose **Add address** below the address list.
3. Enter a handle, such as `hello` or `support`.
4. Select the workspace's default domain or a verified custom domain.
5. Create the address, then select it in the sidebar to open its inbox.

Handles use lowercase letters and numbers, with single dots, underscores, or hyphens between groups. Start and end with a letter or number. Each complete email address must be unique.

New addresses created through this flow are assigned to the member who creates them.

## Choose a domain

- **Default workspace domain:** available without configuring your own DNS. It uses the workspace's generated slug followed by `.selfmail.app`.
- **Custom domain:** must belong to the current workspace and be verified before it can be selected. Follow [Custom domains](/domains) first.

## Troubleshooting

If an address already exists, choose another handle or domain. If a custom domain is missing from the selector, check that you are in the correct workspace and that the domain has been verified.
